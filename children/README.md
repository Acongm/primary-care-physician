## 按问题选择

| 科室 | 重点问题 |
| --- | --- |
| 普通儿科 | 儿童常见发热、一般感染、腹泻、呕吐及综合评估 |
| 儿童呼吸科 | 咳嗽、喘息、哮喘、肺炎，按儿童年龄分组检索 |
| 儿童眼科 | 视力筛查、屈光检查、近视发生与进展、专业随访 |
| 儿童口腔科 | 龋齿风险、含氟防龋、窝沟封闭、刷牙与口腔检查 |
| 儿童耳鼻咽喉科 | 扁桃体、腺样体、中耳炎、听力、打鼾及睡眠呼吸 |
| 儿童保健科 | 身高体重、生长曲线、发育监测、青春期与儿童内分泌 |
| 儿童过敏与免疫科 | 鼻炎、食物与药物过敏、过敏评估及相关皮肤问题 |
| 儿童皮肤科 | 湿疹、皮炎、荨麻疹、感染相关皮疹等 |

## 使用方式

1. 根据人群和主要问题选择技能；具体年龄范围以原文为准。
2. 读取 `SKILL.md` 的工作流程，再按需读取同一技能的 `references/guidelines.md`。
3. 引用具体医学建议前打开原发布方，核对版本、适用人群、章节和证据范围。
4. 以包含 `SKILL.md` 的科室目录作为独立技能单元，保留其中的 `agents/` 和 `references/`。

科室之间的文献链接用于补充查阅；每个技能均保留自己的参考资料。患者病史仅用于当前授权任务，不写入技能或公开仓库。
