# 儿科资料导航

资料核验日期：**2026-11-02**。本组面向儿童及青少年的日常健康资料检索。各文件收录中国官方文件、学会指南、医院临床路径和患者教育，帮助选择检索方向、理解医生讨论的问题和准备就诊资料。

## 阅读与使用顺序

1. **先确认人群。** 记录实际年龄，婴儿必要时记录月龄；新生儿、学龄前儿童、学龄儿童和青少年的资料不能直接互换。涉及生长曲线时还要匹配性别、年龄范围和所用标准。
2. **先看问题，再找病名。** 尚未确诊时从症状或普通儿科入口查起；已确诊后再读对应疾病指南。不要把搜索结果中的相似症状当成诊断。
3. **先读中国现行规范，再对照国际资料。** 对照时记录适用人群、医疗场景、指南版本和证据范围。国外药品批准范围、疫苗程序和医疗服务安排需要本地化核实。
4. **区分资料类型。** 临床指南、专家共识、临床路径、行业标准、证据白皮书和患者科普各有用途；患者版适合理解与沟通，不能替代正式指南的适用条件。
5. **结论要回到具体章节。** 本组文件提供导航和检索词，引用治疗或检查建议前应重新打开原文，确认具体章节、更新日期、推荐强度及是否仍为现行文件。

## 维护约定

只保存链接、书目信息和原创导航说明，不镜像指南全文、图片或受限制的 PDF。动态网页按“本次核验日期”记录，固定版本指南保留版本号；发现新版时补充替代关系，而不是仅把旧年份改成新年份。首次使用、实际就诊前及发现重大更新时，应重新核对来源。

本组不存储任何个人或家庭病史，也不生成个体药物剂量、疗程和处方。遇到紧急情况，应按当地急救流程处理；不能等待资料检索完成才求助。
