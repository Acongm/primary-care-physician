# Adult Urology（泌尿外科）

先把问题分为排尿症状、包皮龟头局部症状或勃起功能问题，再选择对应的官方资料。
保留泌尿外科与相关男科场景的区别；女性排尿问题也可查匹配的泌尿感染章节。

## 先识别需及时处理的情况

- 遇到突然剧烈睾丸疼痛、包皮翻起后卡住无法复位，先建议急诊评估，不沿普通炎症路径继续询问。
- 持续痛性勃起、完全无法排尿，或排尿问题伴明显全身不适时，优先明确紧急就医需要。
- 发热、寒战、腰背痛或快速恶化时，单独检查系统感染与特殊风险信息，避免只解释为局部尿路不适。
- 核对具体急症边界时查 [NHS Testicle pain](https://www.nhs.uk/symptoms/testicle-pain/)、[Tight foreskin](https://www.nhs.uk/conditions/phimosis/) 或 [Priapism](https://www.nhs.uk/symptoms/priapism-painful-erections/)。

建议当地合适的急诊或及时医疗评估，不让资料检索、照片或完整病史收集延误处理。

## 围绕一个分支收集信息

| 分支 | 最少关键输入 |
| --- | --- |
| 排尿问题 | 尿痛/尿频/尿急或尿潴留、持续时间、是否发热腰痛或血尿、是否反复 |
| 包皮龟头问题 | 不适部位、红肿/痒/痛/破损、持续时间、清洁或用品变化、是否影响排尿 |
| 勃起问题 | 发生时间、持续还是间歇、是否伴疼痛、已有评估及相关用药 |

仅在影响指南适用性时询问相关生理结构、妊娠、导尿、免疫状况或重要合并疾病。
谈及性接触或感染检测时解释其用途，允许用户不答；不要推断伴侣行为、性取向或感染来源。
用户只查指南时直接提供资料路径，不要求披露个人经历或发送私密照片。

## 核查版本与适用性

- 对EAU打开当前版本说明和具体章节，记录年份；不要把持续更新页面一律标成参考文件核验年的版本。
- 对IUSTI区分标题中的版次与正式发表年份；核对是否出现后续替代文件。
- 将中国专家共识与正式指南分开标记；期刊写Open Access也不等于本次已读到全文。
- 只读到索引、摘要或介绍时，明确内容边界，不推导未见的处方或检测建议。
- 对实际登录限制、验证页或抓取失败分别描述，改查开放官方替代源，不绕过限制。
- 未联网时，明确不能核对当前EAU版次，只给既有导航及条件性解释。

## 输出有针对性的就诊准备

1. 先说明急迫程度，再指出本次采用的是哪一个问题分支。
2. 用已读证据解释为什么需要相应的病史、体检或检测，不根据在线描述确认病因。
3. 为关键解释附机构、完整标题、版本/日期、具体章节、URL与实际访问范围。
4. 对排尿问题整理是否需尿检/培养、复发或特殊风险如何改变评估等问题。
5. 对局部症状整理是否考虑刺激、皮肤病或感染、是否需要检查以及何时复评等问题。
6. 对勃起问题整理药物、身体状况和心理因素如何纳入评估的问题，避免羞辱或简单归因。

不提供个体抗感染药或改善勃起药的剂量、疗程，也不建议自行停换处方药。
不要把指南中针对特定感染或人群的建议扩大为所有尿路、包皮龟头和男科问题的统一处理。

## 协调跨科与隐私

皮肤表现可提示皮肤科评估，外阴阴道症状可提示妇科，涉及性传播感染时中性说明专门门诊用途。
跨科技能可选，缺少其他技能时仍提供必要的官方来源和就诊问题。
只在本轮使用相关资料，不保存性健康经历、私密图像、检验记录或身份信息到仓库与长期档案。
