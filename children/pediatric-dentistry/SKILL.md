# Pediatric Dentistry（儿童口腔科）

## 先区分预防咨询和急性牙科问题

- 确认用户要了解日常防龋、已有龋齿、检查报告、专业预防措施还是牙痛与外伤。
- 若出现面颈部明显肿胀并伴吞咽或呼吸困难、严重全身不适等情况，先提示立即就医或联系当地急救。
- 若有牙外伤、牙脱位或持续明显疼痛，优先安排及时牙科评估；不要只提供刷牙、涂氟或窝沟封闭资料。
- 对急性问题查找相符的专业路径，不把本技能的防龋参考资料当作所有儿童牙病的完整指南。

## 获取年龄、牙列和风险背景

- 询问实际年龄、所指牙位、乳牙或恒牙、是否处于替牙期，以及目前是无症状预防还是已有不适。
- 询问牙医已经观察到的龋损、修复、封闭或萌出情况；明确哪些内容是家长观察、哪些来自检查。
- 讨论风险时了解既往龋病、刷牙协助、牙膏标签、含糖食饮频率及相关饮水背景，避免只根据一个习惯判断风险。
- 讨论含氟产品时核对产品类型和使用情境；把家庭牙膏、牙医专业措施和全身补充分别记录。
- 不根据年龄猜测具体牙位或已经萌出的牙；只补问会改变资料分支的信息。

## 核对版本、章节与实际可访问内容

- 从 AAPD 原文页面核对文章标题、Last Revision、适用人群和所读章节；不要把 Reference Manual 的年度等同于每篇文章修订年。
- 对联合指南核对发布机构、原文版本和后续更新；对中国早期服务规范查是否有现行替代或补充要求。
- 核实不同资料的类型：Best Practice、正式临床指南和患者教育不能统一标为“指南推荐”。
- 标明全文、推荐章节、官方摘要或索引的阅读层级；仅见标题时不声称已核验具体用法，访问错误不等于收费。
- 无法联网时说明现行版本和具体推荐未核验，提供官方链接与待查关键词。

## 输出可用于牙科咨询的结果

- 先说明年龄与牙列所对应的资料路径、急性问题是否需要先评估，以及现有信息的局限。
- 用简表区分家庭日常措施、专业预防措施和已发生病变的处理讨论，分别链接原始来源和相关章节。
- 解释龋病风险、含氟措施和窝沟封闭的不同目的，不将一种措施描述为对其他措施的保证或替代。
- 准备问诊问题：需要评估哪些牙、当前龋病风险依据是什么、某项措施适用哪些牙位，以及复查应观察什么。
- 对家长给出的产品或方案，只解释标签、证据适用范围及需要牙医确认的事项，不拟定个体用量、浓度或疗程。

## 遵守使用边界

- 不凭照片确定龋损深度或是否需要治疗，不对牙外伤给出未经查证的家庭复位操作。
- 不把成人牙科建议直接用于乳牙或儿童恒牙；资料超出年龄范围时重新寻找相符来源。
- 直接说明必要的转诊方向，无需依赖兄弟技能；遵守来源许可，保留必要链接和原创解释。
- 不将儿童口腔照片、报告、习惯记录或身份信息存入技能及持久资料。
