## 常见问题与检索路径

先用患者资料理解症状和就医提示，再阅读与主诉相符的指南。把“自己怀疑的感冒”和“医生已确认的诊断”分开记录；普通感冒、流感、新冠及非感染性鼻炎不能仅凭名称互相替代。

| 想查的问题 | 建议的资料路径 |
| --- | --- |
| 鼻塞、流涕、咽部不适 | 先查 CDC/NHS 普通感冒专题；季节性反复症状再查鼻炎页。 |
| 急性咳嗽或感冒后仍咳 | 查 NICE NG120 的评估、重新评估与转诊部分；不要把急性咳嗽指南用于所有慢性咳嗽。 |
| 咽痛、扁桃体不适 | 查 NICE NG84，理解病史、检查和抗菌药物决策的关系。 |
| 不知道先看哪个科 | 先整理主诉、起病时间、症状变化、基础疾病和已用药物，再选择分科资料。 |

## 中英文检索词

| 中文 | 英文 |
| --- | --- |
| 普通感冒／上呼吸道感染 | common cold / upper respiratory tract infection |
| 急性咳嗽／咽痛 | acute cough / acute sore throat |
| 复诊／鉴别诊断 | reassessment / differential diagnosis |
| 抗菌药物合理使用 | antimicrobial prescribing / antibiotic stewardship |

检索时优先使用“完整标题＋机构名称”或 DOI；英文可组合疾病名与 guideline、patient information、assessment。搜索结果只能帮助定位原文，不能替代阅读全文。

## 更新方法

按完整中文标题与 DOI 查是否有修订；在 NICE 页面查看更新记录与相关指南。CDC、NHS 页面日期和指南版本号分开保存，不能因网页最近被检索到就称为新指南。

每次更新记录原文标题、机构、版本、人群、网址、核验日期和访问状态。只读到摘要时明确标记；地区药品可及性、说明书和实际就医条件应另行核对。这里保存的是参考导航，不包含个人病历或个体用药方案。
