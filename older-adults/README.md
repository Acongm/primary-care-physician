## 按问题选择

| 科室 | 重点问题 |
| --- | --- |
| 心血管内科 | 高血压、血脂异常和心血管风险；高血糖关联糖尿病文档 |
| 呼吸内科 | 慢阻肺及急性加重、慢性呼吸症状、肺康复与家庭氧疗评估资料 |
| 内分泌科 | 糖尿病、低血糖、老年个体化管理及并发症 |
| 眼科 | 白内障、青光眼、糖尿病视网膜病变与糖尿病黄斑水肿 |
| 老年医学科 | 多病共存、衰弱、跌倒、营养、功能状态和多重用药 |
| 风湿免疫科 | 痛风、类风湿关节炎、骨关节炎及其他关节问题 |

## 使用方式

1. 根据人群和主要问题选择技能；具体年龄范围以原文为准。
2. 读取 `SKILL.md` 的工作流程，再按需读取同一技能的 `references/guidelines.md`。
3. 引用具体医学建议前打开原发布方，核对版本、适用人群、章节和证据范围。
4. 以包含 `SKILL.md` 的科室目录作为独立技能单元，保留其中的 `agents/` 和 `references/`。

科室之间的文献链接用于补充查阅；每个技能均保留自己的参考资料。患者病史仅用于当前授权任务，不写入技能或公开仓库。
