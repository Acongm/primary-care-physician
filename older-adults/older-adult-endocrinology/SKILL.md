# Older Adult Endocrinology（内分泌科）

围绕老人实际健康与功能状态解释内分泌证据，优先查阅对应人群章节。

## 1. 识别问题并保留关键背景

- 区分糖尿病长期管理、低血糖疑问、监测报告解释和甲状腺或骨健康问题。
- 收集具体年龄、已明确病种及分型、问题时间线、当前医疗团队制定的计划。
- 解释血糖时保留原单位、测量时间、进食关系和测量方式，区分指尖血糖、糖化指标与连续监测。
- 收集既往低血糖、近期进食变化、认知与日常功能、照护支持、衰弱和肾功能信息。
- 核对实际使用的药品和近期处方变化；缺少信息时标注缺口，避免由年龄推定风险或目标。
- 解释甲状腺或骨相关报告时保留原文术语及既有专科判断，不迁移糖尿病框架。

## 2. 优先识别可能急迫的场景

- 用户描述正在发生的意识异常等可能急迫表现时，先建议立即联系急救或专业医疗服务，不等待完成资料核对。
- 低血糖相关问题先确认是在回顾既往事件还是描述当前变化，避免把长期随访资料用于替代即时评估。
- 无法判断时说明关键缺失信息，不根据一个数值、症状或药名给出个人确诊与调药结论。

## 3. 按分支读取证据

先读取 [references/guidelines.md](references/guidelines.md)，再选择最相关的官方入口。

| 分支 | 优先来源 | 查阅方向 |
|---|---|---|
| 老人的糖尿病目标与治疗负担 | 中国老年糖尿病指南、ADA 老人专章 | 功能、认知、共病、个体化评估 |
| 血糖或糖化、连续监测报告 | ADA 现行标准相应章节 | 监测方式、结果解释与适用条件 |
| 低血糖风险和照护沟通 | ADA 老人及相关章节、NIDDK | 背景风险、信息记录、复诊问题 |
| 甲状腺问题 | ATA 指南与声明 | 病种、成人范围、老人及共病条件 |
| 骨质疏松及其他内分泌问题 | Endocrine Society | 具体疾病与人群范围 |

## 4. 确认版本和原文范围

- 从 ADA 固定入口核对当前版，再打开 Older Adults 专章；不要把参考文件记载年份自动视为当前年份。
- 核对中国指南题名版本、实际发表时间、更新或勘误，并读取对应问题章节。
- 将成人总体、老人、儿童及妊娠内容分别处理；保留原文健康状态和功能分层条件。
- 对目标、监测和治疗负担的解释，明确哪些适用条件已知、哪些仍需临床评估。
- 解释“去强化”等概念时说明需要专业评估，避免将其转换为根据年龄自行停药的决定。
- 原文访问受限或只见摘要时如实标注，不重建未读的表格、目标或管理算法。
- 未联网时明确版本尚未核验，只提供目录、术语解释和待查原文问题。

## 5. 形成回答和复诊材料

1. 先说明问题类型及是否涉及当前急迫变化，再解释本次资料能支持到什么程度。
2. 提供官方标题、机构、版本、具体章节和链接，并注明读取范围与人群适用性。
3. 将报告事实、指南内容和需要确认的推断分开表达，保留原始单位和时间背景。
4. 列出影响目标或监测解释的信息缺口，如功能状态、低血糖背景或肾功能。
5. 整理向医生询问的管理目标、监测用途、低血糖预防计划和照护安排，不生成个人药物方案。

## 6. 协作和数据边界

- 血压血脂问题可选用 older-adult-cardiology，眼底问题可选用 older-adult-ophthalmology。
- 多药、功能下降和照护负担可选用 older-adult-geriatric-medicine；其不可用时仍完成当前证据说明。
- 不开具个人剂量、疗程或自主停换药计划，也不从摘要推导个人急救操作。
- 不将个人血糖记录、药品清单、检查报告或身份资料保存进技能、仓库或其他持久化文件。
