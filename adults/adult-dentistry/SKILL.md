# Adult Dentistry（口腔科）

把日常保健、龋损、牙周问题和急性牙痛肿胀分别组织成资料路径。
先确认用户需要预防建议、解释已有牙科检查，还是为当前症状准备就诊。

## 先判断牙科急迫程度

- 口腔或颈部肿胀伴呼吸、说话或吞咽困难时，先建议当地急诊评估，不等待牙齿保健资料查询。
- 明显面颊/颌部肿胀、发热、剧烈牙痛或张口困难时，优先说明及时牙科评估需要。
- 参照 [NHS Dental abscess](https://www.nhs.uk/conditions/dental-abscess/) 核对危险信号；不要从疼痛和肿胀直接确认脓肿。
- 对持续口腔黏膜病损另查口腔黏膜专科评估路径，不用防龋或牙周资料代替。

## 询问与当前分支有关的信息

| 分支 | 最少关键输入 |
| --- | --- |
| 日常清洁与防龋 | 主要想改善的习惯、是否已有牙医风险评估或特别要求 |
| 已发现龋损 | 牙医如何描述病变、具体牙位/牙面及有无疼痛；允许未知 |
| 牙龈或牙周问题 | 出血/肿胀/松动、持续时间、已有牙周检查或维护安排 |
| 牙痛或肿胀 | 部位、开始时间、冷/热/咬合等诱因、是否肿胀发热或影响张口吞咽 |

仅在影响来源适用性时询问免疫状态、重要合并疾病、妊娠和相关用药。
用户只找资料时直接导航；不要要求用户自行诊断牙髓、根尖周状态或测量牙周袋。

## 核验正式版次与具体章节

- 对ADA打开相关原始指南入口及推荐内容，核对是否已有替代版；介绍页只能支持实际可见的信息。
- 对SDCEP核对当前正式版次和网页更新记录；参考清单中的版次是核验时的记录，后续应检查替代版，并区分临床建议修订与支持工具增补。
- 对含氟、家庭护理和国家卫健委核心信息标明专题或健康教育身份，不把它们称为新发布疾病指南。
- 对牙痛抗菌药指南检查纳入与排除人群，不外推到所有口腔感染、免疫受损或其他特殊情况。
- 仅取得摘要、概览或索引时明确证据范围；登录、抓取失败和收费信息分别描述。
- 未联网时，说明尚未核对最新版本或网页变动，仅提供已有来源导航和一般解释。

## 输出能用于牙科沟通的结果

1. 先说明急迫程度，再按预防、龋损、牙周或急性症状这一主要分支回答。
2. 解释家庭护理、专业检查与牙科操作各自解决的问题，不把保健产品当作诊疗替代品。
3. 为关键解释附机构、完整标题、年份/版次、章节、原始URL及实际读取范围。
4. 对龋损整理“病变属于哪一阶段”“为何选择此类处理”“需要怎样复查”等问题。
5. 对牙周问题整理“检查结果说明什么”“家庭清洁怎样配合专业维护”“复评看哪些变化”等问题。
6. 对牙痛肿胀整理“需要什么牙科检查或操作”“抗菌药是否适用及依据”“何种变化需立即复诊”等问题。

不根据疼痛位置远程确诊，不给个体药物剂量、疗程或自行启停处方药指令。
不要让用户自行使用高浓度专业用氟产品，也不要将抗菌药解释为所有牙痛的统一解决方法。

## 处理相关问题与个人资料

咽部疼痛和口唇皮肤问题可分别提示普通内科或皮肤科资料；牙齿、牙周与口腔黏膜问题保持明确区分。
孕期口腔问题另核对相应资料；跨科技能可选，不影响本轮完成基础导航。
不把牙片、检查报告、个人用药和身份信息写入技能、仓库或长期档案。
