# 老人资料索引

核验日期：2026-11-02。本目录按家庭查资料的常见问题组织，收录中国官方或原出版方资料、国际专业指南及官方患者教育。

“老人”仅为家庭用途分组，不为所有指南设置统一年龄阈值。实际使用需要核对具体年龄、疾病及病程阶段、衰弱、认知与日常功能、肾功能、多病共存和照护条件。资料帮助准备就诊问题、理解医生安排，不直接生成个人诊断、处方或停换药决定。

## 推荐查阅顺序

1. 选择最接近的问题入口；尚不清楚归属或有多种问题时先读老年医学分册。
2. 用患者教育理解术语，再用中国指南和国际指南核对诊疗依据。
3. 对照实际年龄、病种、病程和共病阅读对应章节，保留原文版本和范围。
4. 将资料整理为就诊问题：还缺什么信息、为什么安排检查、管理目标如何确定、如何复评。
