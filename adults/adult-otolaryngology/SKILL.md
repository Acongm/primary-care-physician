# Adult Otolaryngology（耳鼻咽喉科）

围绕鼻炎相关主诉选择官方资料，帮助成年人把症状、环境暴露和生活影响整理成就诊线索。
把本技能的重点保持在过敏性与非过敏性鼻炎；遇到听力、眩晕、喉部肿物等问题，另匹配专病来源。

## 先区分急症与鼻炎资料查询

- 遇到喉舌或口唇突然肿胀、严重呼吸困难、晕厥等表现，先建议当地急救评估，不按普通鼻炎继续观察。
- 需要核对严重过敏信号时查 [NHS Allergies](https://www.nhs.uk/conditions/allergies/)；不要让资料检索延误求助。
- 同时有喘息或原有哮喘明显加重时，单独评估呼吸问题，不能仅解释为鼻炎带来的不适。
- 对持续单侧鼻塞、反复出血或明显面部疼痛，指出需要耳鼻喉面诊的原因，并另查对应评估路径。

## 只询问决定分支的信息

1. 确认主症状是堵塞、清涕、喷嚏还是鼻痒，以及持续时间、单侧或双侧。
2. 询问是否随季节、住所、工作环境、动物或其他暴露变化；把时间关联保留为线索，不当作已确认过敏原。
3. 询问睡眠和日常活动影响，以及是否伴眼痒、眼红、喘息或发热。
4. 需要讨论治疗经历时，取得现有鼻喷剂或其他产品的准确名称、使用方式与效果。

只做资料导航时直接检索，不要求提供上述个人信息。
不要要求用户自行进行过敏原暴露或凭单一症状选择检测套餐。

## 根据鼻炎问题选源

按需读取 [references/guidelines.md](references/guidelines.md)，利用其中标题与检索词定位所需章节。

| 当前问题 | 选择来源 | 重点核对 |
| --- | --- | --- |
| 了解鼻炎与常见诱因 | NHS Allergic rhinitis、AAAAI Hay Fever / Rhinitis | 患者可理解的症状、生活影响及就医条件 |
| 比较过敏性与非过敏性鼻炎 | AAAAI/ACAAI Rhinitis 2020 | 评估、病史与检查的适用情境 |
| 了解专业诊疗路径 | AAO-HNSF Allergic Rhinitis 指南 | 诊断评估、检测与治疗决策的前提 |
| 查中国诊疗依据 | 中国变应性鼻炎诊断和治疗指南 | 2022修订版的原始期刊记录及后续替代版本 |
| 鼻症状与眼痒同时出现 | 鼻炎来源加独立眼科来源 | 鼻部与眼部危险信号及两者证据范围 |

将“鼻部症状支持进一步评估过敏”与“已确认过敏性鼻炎”分开表达。
不要把鼻喷剂归为同一种药物，也不要把对某种产品的反应作为确诊证据。

## 阅读适用条目并核对版本

- 检查成人条目、建议适用条件及是否为最新可确认的正式版本；不要把2015或2020标题年份自动称为现行最新版。
- 区分中国指南的期刊目录、AAO-HNSF介绍页与AAAAI完整实践参数，各自只支持已读到的内容。
- 需要解释过敏检测、免疫治疗或合并哮喘时，进一步打开相应章节，不从概览推导个人适应证。
- 对公开PDF只摘取任务所需的简短信息并提供链接，不复制整份全文。
- 全文需要登录或抓取失败时，说明实际证据缺口，改用开放官方页面补充基础解释。
- 未联网时，保留历史版本标签，明确尚未核对后续更新。

## 形成就诊准备

1. 先给出急迫程度，再用“症状—时间—暴露—生活影响”概括用户提供的线索。
2. 说明哪些问题鼻炎指南可以回答，哪些仍需要鼻部检查或其他专科评估。
3. 为关键解释附来源机构、标题、版本、章节和可访问链接，标明指南、实践参数或患者教育。
4. 准备可向医生询问的问题：是否需要检测、如何判断检测与症状相关、现有鼻喷方式是否正确、合并眼部或呼吸问题如何评估。
5. 若用户需要长期观察表，仅在当前答复中列出症状频率、环境变化、睡眠影响与已用产品，不创建个人健康档案。

可以解释已读资料中不同处理类别的作用与选择依据，不给个体剂量、疗程或自行启停药物指令。
不要为了验证过敏而建议自行接触疑似过敏原。

## 保持眼部与其他问题的边界

把眼痛、畏光或视力变化转入独立眼科急迫性判断，不以“鼻炎伴眼痒”一概解释。
若用户只问鼻炎，保持回答聚焦；跨科技能可选，未安装时仍完成必要的来源导航和就诊准备。
不要把个人症状、住址、工作暴露或用药记录保存到技能、仓库或长期记录。
