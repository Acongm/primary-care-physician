# Older Adult Cardiology（心血管内科）

围绕用户当前的心血管问题选择证据，给出可追溯的解释和就诊准备材料。

## 1. 明确问题和关键输入

- 先区分血压测量、血脂报告、既往心血管病管理与三高综合复诊。
- 收集具体年龄、问题持续时间、已确认诊断及本次最希望解决的问题。
- 解释血压记录时询问测量场景、时间、原始单位、重复记录及站立相关不适。
- 解释血脂时保留完整项目、原单位和既往心脑血管事件背景。
- 补充衰弱、日常功能、肾功能、多种药物及近期处方变化；将未知项明确标为未知。
- 只询问影响证据选择的信息，避免索取姓名、证件、住址等身份资料。

## 2. 先处理可能急迫的变化

- 对新发胸痛、明显呼吸困难或迅速恶化等用户描述，优先建议及时接受线下评估；不要等待完成文献比较。
- 对稳定随访问题进入后续检索，避免用单个测量值自行排除风险或确诊疾病。
- 资料不足时说明无法确定急迫程度，并指出最影响判断的缺失信息。

## 3. 按问题选择来源

先读取 [references/guidelines.md](references/guidelines.md)，按以下分支选择原机构入口。

| 当前问题 | 优先查阅 | 需要定位的内容 |
|---|---|---|
| 家庭与诊室血压不同 | 中国高血压指南、NICE NG136 | 测量方式、确认流程、体位性问题 |
| 老人的血压管理目标 | ESC 高血压专题、中国指南 | 年龄、衰弱、共病与耐受相关章节 |
| 血脂异常和风险评估 | 中国血脂指南、NICE NG238 | 风险分层、既往事件、一级或二级预防 |
| 理解复诊与长期管理 | ESC 患者版及对应专业指南 | 患者解释和正式推荐的对应关系 |
| 三高中血糖部分 | 本组内分泌证据 | 糖尿病类型、低血糖及老人专章 |

## 4. 核对证据和适用性

- 联网打开官方专题或原出版方页面，核对现行版本、替代关系、勘误及具体章节。
- 将参考文件核验日视为历史记录；保留本次实际查阅日期，不自动宣称资料最新。
- 区分普通成人、老人、衰弱和合并肾病等人群，逐项解释哪些条件已匹配、哪些仍不清楚。
- 比较国内外材料时保留测量定义、风险分层和医疗环境差异，不直接移植国外风险模型。
- 仅引用已读取的推荐；保留目标或检查要求对应的人群和条件，不抽出孤立数字。
- 遇到登录、403、动态页面或全文不可读时说明访问状态；仅见摘要时标注证据不完整。
- 未联网时提供已有入口和待核验清单，明确尚未确认现行版本，不补写缺失推荐。

## 5. 组织回答

1. 先说明本次查阅覆盖血压、血脂还是整体复诊，以及是否需要优先线下评估。
2. 用简短表格列出来源标题、机构、版本、具体章节、原文链接和访问状态。
3. 结合已知信息解释推荐的适用条件，区分指南原意与基于有限信息的推断。
4. 单列仍需医生确认的条件及其影响，避免把不确定性写成确诊结论。
5. 整理复诊问题和可携带的血压记录、完整报告、药品清单；围绕用户最关心的问题排序。

## 6. 保持范围与隐私边界

- 将三高明确拆为血压、血脂、血糖；血糖细化可选用 older-adult-endocrinology，不以其已安装为前提。
- 对衰弱、跌倒或多药协调问题，可选用 older-adult-geriatric-medicine；缺少该技能时继续依据本页相关原始来源完成说明。
- 解释既有治疗安排及应向医生核实的事项，不生成个人药物剂量或自主停换药方案。
- 仅在当前回答中使用必要病情信息，不把报告、身份资料或家属病史写入技能、仓库或持久化文件。
