# 成年人：按问题查找专业资料

核验日期：2026-11-02。

本目录以成年人的日常健康问题为入口，分别收录中国官方或原始期刊资料、国际临床指南、临床专题和患者教育。用于查找证据、理解医生的评估思路和准备就诊问题；不会把网页清单变成个人诊断或处方。

## 如何使用

1. 先根据主要问题选择页面，记录起病时间、变化、已做检查和当前用药等信息；没有的信息写“未知”。
2. 先阅读官方患者教育，获得基本概念和就医提示，再查匹配年龄、疾病、严重程度及医疗场景的指南。
3. 需要引用具体建议时，打开原文查看相应章节及更新记录；只读到标题或摘要就不能宣称已经核对完整推荐。
4. 把待确认的问题整理给专业人员，保留检查结果的日期、单位、参考范围及医生已经给出的计划。

## 资料类型与访问状态

- 临床指南／实践参数：提供系统性的专业推荐，适用范围需逐篇确认。
- 专家共识：说明其共识性质，不因标题含“诊疗”就统一改称循证指南。
- 临床综述／专业专题：帮助理解证据与评估思路，不能自动赋予指南级别。
- 患者教育／健康教育材料：适合日常阅读和理解求助提示，与专业处方依据分开保存。
- “已读取网页”只描述本次访问情况；“仅索引或摘要”不表示阅读全文。抓取403、402、超时等不等于网站一定收费，只有官方访问说明可支持相应判断。

每篇文件保留具体来源、用途和访问情况。较早指南明确保留版本年份，不声称为最新；外部资料版权仍归原发布者。

## 适用范围

本目录没有覆盖成年人全部疾病，也不把儿童、孕期、免疫功能受损或复杂共病患者的方案纳入普通成人路径。其他年龄和跨科资料从[总目录](../README.md)进入；涉及儿童的资料需要单独核对年龄范围，不能直接套用。

这些文件是普通参考Markdown文档，不是安装型技能，也没有收录任何个人病历。若后续以其建立检索流程，应继续保留来源类型、版本、人群和权限边界，并在使用具体内容时重新核对原文。
