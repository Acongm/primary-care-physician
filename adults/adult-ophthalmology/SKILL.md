# Adult Ophthalmology（眼科）

围绕眼红、眼痒、分泌物和疑似结膜炎建立眼科资料路径，并保留“眼红尚未明确病因”的表述。
即使同时出现喷嚏或流涕，也先独立处理眼部症状，不直接套用鼻炎结论。

## 先检查影响视力的信号

- 先问是否有眼痛、畏光、视力改变、眼外伤或化学物接触，不先按“红眼病”提供常规处理清单。
- 突然视力下降、严重眼痛或眼部损伤时，先建议及时急诊或眼科急诊评估，不等待在线查证结束。
- 隐形眼镜使用者出现红眼时，单独询问疼痛和视力变化，并明确其需要专业评估的意义。
- 参照 [NHS Eye pain](https://www.nhs.uk/symptoms/eye-pain/) 和参考文献中的结膜炎患者专题，按严重程度说明就医渠道。

不要把未报告的危险信号当成已经排除；信息不足时说明仍需确认的关键点。

## 取得最少但具体的眼部信息

1. 确认成人范围，询问单眼或双眼、开始时间及先后顺序。
2. 区分痒、异物感、疼痛、畏光、流泪与分泌物，不把这些词相互替代。
3. 询问隐形眼镜、近期眼科手术或治疗、外伤及正在使用的滴眼液；只追问与当前问题相关的项目。
4. 按需补充接触类似症状者、季节性或环境关联、是否伴鼻部症状。

用户只查询资料时直接导航；用户提供照片时只描述可见特征和拍摄限制，不能据照片确诊或排除严重病变。
不要要求上传包含面部身份或其他无关个人信息的图像。

按需打开 [references/guidelines.md](references/guidelines.md)，保留来源的资料类型及原访问状态。

| 问题 | 优先来源 | 不要越过的范围 |

| 理解不同结膜炎病因 | CDC Clinical Overview of Pink Eye | 临床专题不是完整正式临床实践指南 |
| 了解何时就医及一般照护 | CDC、NEI、NHS患者专题 | 只解释成人部分，不套用新生儿段落 |

| 询问是否传染 | 官方页面对应的病因段落 | 未确定病因时避免统一判断“会传染”或“不会传染” |
| 需要AAO专业资料 | 参考文件中的AAO人工导航 | 遵守其AI使用声明，不抓取、转存或改写受限指南正文 |

不要仅凭分泌物颜色、单眼或双眼、伴鼻炎就确定细菌性、病毒性或过敏性病因。
需要超出结膜炎的解释时，另查相应官方眼科专题并说明扩展范围。

## 核查现行页面与可见证据

- 打开原始机构页面，确认标题、更新时间、适用人群与将要解释的具体段落。
- 对中国历史共识检查是否有替代版本；未找到不等于不存在更新。
- 将专业临床综述、专家共识和患者教育分别标记，不人为提高来源级别。
- 只读到摘要或索引时，不推断详细治疗方案；可提供可读的CDC、NEI或NHS页面补充。
- 不绕过登录、访问限制或明确的AI使用限制，也不把自动抓取失败说成付费证明。
- 未联网时，说明无法确认现行版本，并把输出限定为已有导航与一般解释。

## 输出眼科就诊准备

1. 先说明哪些症状决定是否需要及时眼科评估，再概括已知的单/双眼和时间线。
2. 解释资料支持的不同评估方向，明确哪些问题需要视力、角膜或其他现场检查才能判断。
3. 为每个关键解释附机构、页面或共识标题、年份/访问日期、段落与链接，并标明读取范围。
4. 整理针对性的就诊问题，例如隐形眼镜相关风险、是否需要检查角膜、现有滴眼液是否适合、何时应复诊。
5. 若涉及传染防护，只按已读官方资料给一般措施，保留病因尚未明确的限制。

不要提供个体滴眼药剂量或疗程，不建议自行试用处方抗菌药或激素滴眼液来验证病因。
不要把症状改善视为病因已确认，也不要用在线解释替代必要的眼科检查。

## 处理跨科与隐私

只有当鼻痒、喷嚏等另有需要时，补充耳鼻咽喉科资料；保持眼科结论独立。
跨科技能可选，不将安装其他技能作为获得眼科资料的条件。
只在本轮使用必要信息，不保存眼部照片、报告、个人症状或身份信息到仓库与长期档案。
